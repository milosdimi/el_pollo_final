## Gameplay

- **Run & Jump** — navigate Pepe through the level
- **Collect items** — grab coins and tabasco bottles
- **Fight enemies** — defeat chickens by jumping on them or throwing bottles
- **Boss fight** — face the final enemy at the end of the level

## What I learned

This project was built to practice and deepen:

- **Object-Oriented Programming (OOP)** — classes, inheritance, encapsulation
- **Browser Events** — keyboard input, collision detection, game loop
- **Canvas Rendering** — animating sprites and game objects
- **Advanced JavaScript** — intervals, image caching, audio management
